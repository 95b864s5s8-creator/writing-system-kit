# writing-system-kit · 人写AI辅写作系统

一套可随身携带、任何 AI agent 都能用的写作系统。**人主导，AI 辅助**——作者决定选题、观点、结构与审美，AI 只做激发灵感、结构方案、润色和成稿。

## 包含什么

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 总入口：触发词、四阶段骨架、快捷命令 |
| `01_核心流程_vibe-writing.md` | 四阶段完整规则（学习→结构→写作→成稿） |
| `02_写作风格档案.md` | 写作偏好：自然段落、判断表达、反模式清单 |
| `03_七技巧方法论.md` | 信息价值+情绪价值落实到每一段（含完整示范） |
| `04_去AI味规则.md` | AI 腔句式清单 + 成稿检查表 |
| `05_安装指南.md` | 各平台安装方法 + 换电脑流程 |

## 快速开始

1. 把整个文件夹复制到你的 agent skill 目录（见 `05_安装指南.md`）
2. 对 agent 说：**"我想写关于XX"**
3. 按四阶段协作：对话学习 → 结构化 → 迭代润色 → 成稿

## 核心理念

- 这是作者的写作系统，不是 AI 的生成系统
- AI 不替作者思考、不替作者决定、不替作者保留
- 作者删掉的内容永远不恢复
- 核心判断永远属于作者
